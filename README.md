
# Python Training 📚

Welcome to the **Python Training** repository! This repository contains all the resources, programs, assignments, and solutions provided by Blue Yonder (Panasonic) as part of the Python training curriculum.

## Introduction

This repository is designed to help you master Python programming through a structured training program. It includes a variety of resources, practical programs, and assignments with solutions to ensure a comprehensive learning experience. Whether you're just starting with Python or looking to refine your skills, this repository provides a solid foundation and advanced topics to enhance your knowledge.

## Programs 💻

The `programs/` directory contains a collection of Python programs that were covered during the training sessions. These programs range from basic examples to advanced implementations, demonstrating various aspects of Python programming, including:

- **Basic Programs**: Covering Python fundamentals like variables, loops, conditionals, and functions.
- **Intermediate Programs**: Exploring data structures, object-oriented programming, and file handling.
- **Advanced Programs**: Focusing on more complex topics such as decorators, generators, and multi-threading.

## Assignments 📝

The `assignments/` directory houses all the assignments given during the training. These assignments are designed to test your understanding and application of the concepts covered. Each assignment is an opportunity to practice and solidify your Python skills.
